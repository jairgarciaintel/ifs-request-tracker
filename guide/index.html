What is the FS Request Tracker?

A private dashboard that connects directly to our SharePoint list and lets us track the internal status of every DA Ops request in real time.

  • Live data — pulls from SharePoint automatically every 10 minutes
  • Shared tracking — both Jenn and Jair see the same statuses instantly
  • Writes back to SharePoint — change the status here, it updates there
  • No installation needed — just open the URL in your browser

How to Access

Step 1: Open the URL

https://jairgarciaintel.github.io/ifs-request-tracker/

Step 2: Enter your name

The first time you open it, a prompt asks for your name. Type Jenn or Jair (case insensitive). It remembers you forever on that browser.

That's it.

No passwords, no installation, no plugins. Just the URL and your name.

Reading a Request Card

  • #ID — Request number from SharePoint
  • Customer — Company name
  • Colored badges — Service types (Portal Creation, New DA, COD, etc.)
  • Status badge — Current SharePoint status (italic, right side)
  • Owner chip — purple chip with who it's assigned to
  • Age badge — Days since created 3d 15d 45d
  • Progress bar — Green line below = % of steps completed
  • Inside: Tech Node, Assigned To/BD/FCE Lead, Portal Name, DA Link, DA Number
  • Click to expand — opens all the internal steps
Intel Confidential

Expanding a Request & Editing Steps

Click on any card to open it. Inside you see:

  • SharePoint Status — dropdown at the top. Change it and it updates SharePoint directly.
  • Internal sub-steps — the detailed steps only we track (Configure AGS, Create Portal, etc.)
  • Your name appears next to any step you change
  • Progress bar updates instantly as you complete steps

Changes save automatically. No save button needed.

Intel Confidential

SharePoint Connection

Two-way sync:

  • SharePoint → Page: New requests appear automatically every 10 min
  • Page → SharePoint: When you change the SharePoint Status dropdown, it updates the list

Valid SharePoint statuses:

Info Requested Acknowledged In Approval Loop Out for Signature WIP IT Request Submitted Complete On Hold Canceled

Internal steps (Configure AGS, etc.) do NOT update SharePoint — only the SharePoint Status dropdown does.

Filters, Search & Sorting

  • Time filter — All 2026 / This Month / Last Month / 2-3 months ago
  • Type filter multi-select — a checkbox menu. Pick several types and it shows requests matching any of them; pick one for just that type; none = all.
  • Assigned To filter — see only requests assigned to a person (or Unassigned)
  • Tech Node filter — filter by technology (Intel 18A, etc.)
  • Status filter — Not Started, In Progress, Complete, Failed
  • Search box — customer, ID, DA number, DA link, portal name or assignee
  • Sort — Newest First / Oldest First / Oldest Unresolved

Stat Pills (clickable!)

Click the colored numbers to filter: WIP, Done, New, ack, canceled. Click multiple to combine. Click "total" to reset.

Automatic Customer Emails

When you change the SharePoint Status, the tracker can email the customer automatically with a branded Intel Foundry message:

  • Acknowledged — request received + SLA table
  • Info Requested — asks for the templates needed per service type
  • Out for Signature — notice it's out for signature
  • In Approval Loop — notice with the ~2–4 day SLA
  • Complete — celebration message (per service type)

Two safety toggles in the header

Auto emails ON/OFF — when OFF, nothing is sent to anyone.

Test mode ON/OFF — when ON, every email goes ONLY to Jair (no customer, no CC). Turn OFF for real sending.

Completing a Request

Set the SharePoint Status to Complete and a popup appears depending on the service type:

  • Portal / New DA — asks for Portal Name + DA Number (auto-fills from a previous request of the same customer if it exists), then emails the customer their portal is ready and to apply for the AGS WebView Access.
  • IFS NDA / MP-NDA / MRUNDA — tells the customer the document is signed and they can start the relationship.
  • COD — a double-confirmation popup (no portal name); the notice CCs Birthe Dallmer and James Matayabas Jr.

Completing marks the progress bar to 100% instantly — no reload.

Codename Requests

When you complete a Codename request, a popup asks for the codename to assign to the company.

  • The codename notice is emailed to the Assigned BD and the FCE Lead / Account Owner.
  • The email is sent encrypted (Intel Confidential — Intel employees only), so it can't leak outside Intel.
  • The popup pre-shows who will receive it before you send.

Assigning Requests

Each card shows three people fields from SharePoint:

  • Assigned To — the iGO Admin owner. editable Click Assign to set Jair or Jenn; it writes to SharePoint.
  • Assigned BD — read-only (Project Contact)
  • FCE Lead / Account Owner — read-only

The owner also shows as a purple chip in the card header, so you can see who's on each request without opening it.

Intel Confidential

Separate Request

Codename and IFS NDA must each live on their own request. When one of them comes bundled with other services, a Separate request button appears inside the card.

  • Click it and confirm.
  • It creates a new request in SharePoint with only that service (Codename or IFS NDA), copying the Assigned BD and FCE Lead.
  • The original request keeps the rest (e.g. New DA + Portal Creation stay together).
  • Both appear separated on the next Sync.

Help Chatbot

Both the tracker and this guide have a help chatbot — the round chat button in the bottom-right corner.

  • Ask questions — type things like "how do emails work?" or "what is Test mode?" and it answers instantly. Suggested questions appear as chips.
  • No AI cost, no setup — it answers from a built-in knowledge base of how the tracker works.
  • Report a bug or feature — click Report it at the bottom of the chat, type what you found or want, and hit Send.
  • The report is emailed to Jair for the next development round. It lands in the inbox (not the tracker-notifications folder), so nothing gets lost.

Use it any time you're stuck or have an idea to improve the tracker.

Tips & Shortcuts

  • Sync button — refresh data from SharePoint immediately
  • Sound toggle new — a bell icon; plays a chime when a brand-new request appears. Click once to unlock browser audio.
  • Excel button — download everything as .xlsx
  • JSON button — download raw data
  • Expand/Collapse All — open or close all cards at once
  • Light/Dark — toggle theme
  • Ctrl+E — expand all (keyboard)
  • Ctrl+W — collapse all (keyboard)
  • ← → — navigate pages
  • Notes field — add comments, IT ticket numbers, or reminders to any request.

Remember:

This does NOT replace SharePoint. It's our internal tracking layer on top of it. SharePoint remains the official record.
